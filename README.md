# Madhuset Løgten – demo

Demo af en hjemmeside til Madhuset Løgten, lavet af OviaSpecs. Ikke Madhusets egen side og ikke godkendt af Madhuset Løgten eller Mondrups.

Indhold, priser og kontaktoplysninger er hentet fra mondrups.com/madhuset den 23.11.2026. Siden er markeret noindex. Ønsker ejeren den fjernet, slettes dette repo.

HTML, CSS og små JS-moduler (prisberegner, forespørgsel, 3D-visning). Mailknapper åbner kun gæstens eget mailprogram.

Fotos i img/ er RAISFOTO og er hentet fra mondrups.com/madhuset til demoen. De fjernes, hvis stedet ønsker det. Intet foto er genereret.

"Se jer omkring" er en 3D-illustration af en mulig bordopstilling (30 og 55 gæster), ikke et 360°-foto af lokalet. Three.js r160 (MIT) ligger i js/vendor/ og hentes kun, når visningen åbnes. Uden 3D vises begge opstillinger som tegninger.
